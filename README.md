# Описание датасета

Название: Impact of Social Media on Life.
Автор публикации на Kaggle: Harish Yadav.
Источник: https://www.kaggle.com/datasets/harishyadav0506/impact-of-social-media-on-life
Файл: Social_media_impact_on_life.csv

## Содержание
4500 записей и 16 столбцов.

## Обоснование выбора
Датасет выбран для изучения связи привычек использования социальных
сетей с продолжительностью сна. Он содержит числовые и категориальные
переменные и подходит для первичного анализа и дальнейшей задачи регрессии.

## Предварительная задача итогового проекта
Предсказание Sleep_Duration_Hours по демографическим характеристикам
и привычкам использования социальных сетей.


Мы исследуем, связано ли использование социальных сетей с продолжительностью сна в этом датасете. Заранее наличие связи не предполагается. Анализ не позволяет установить, что именно вызывает изменения сна.
