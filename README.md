## Данные

### Подержанные автомобили: ПР-1–5 и ПР-7

Датасет **Used Car Price Prediction Dataset**, автор публикации Taeef Najib. Источник: [Kaggle](https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset). Локальный файл: [used_cars.csv](data/raw/used_cars.csv).

В таблице **4009 объявлений и 12 столбцов**. Одна строка — объявление о продаже автомобиля. Цель регрессии — `price`, запрашиваемая цена в долларах США (USD). Она может отличаться от фактической цены продажи.

| Столбец | Значение | Тип по смыслу |
|---|---|---|
| `brand` | Марка автомобиля | Категориальный |
| `model` | Модель и комплектация | Категориальный |
| `model_year` | Модельный год | Числовой |
| `milage` | Пробег в милях; исходное написание столбца сохранено | Числовой, хранится строкой |
| `fuel_type` | Вид топлива | Категориальный |
| `engine` | Описание двигателя | Текстовый |
| `transmission` | Описание коробки передач | Категориальный |
| `ext_col` | Цвет кузова | Категориальный |
| `int_col` | Цвет салона | Категориальный |
| `accident` | Сообщение об авариях или повреждениях | Категориальный |
| `clean_title` | Отметка clean title в объявлении | Категориальный |
| `price` | Запрашиваемая цена, USD | Числовой, хранится строкой |

Полных дубликатов нет. Пропуски: `fuel_type` — 170, `accident` — 113, `clean_title` — 596. В топливе встречаются `–` и `not supported`. Отсутствие сообщения об аварии не гарантирует отсутствие ДТП; пропуск `clean_title` не означает ответ «Нет».

Числовые и категориальные признаки, строковые цена и пробег, пропуски и неоднородные описания позволяют последовательно изучить анализ данных, предобработку и моделирование.

### Кыргызские новости: ПР-6

Источник: [Kyrgyz Multi-Label Topic Classification](https://github.com/alexeyev/kyrgyz-multi-label-topic-classification), [статья авторов](https://arxiv.org/pdf/2308.15952). Корпус содержит новости 24.kg на кыргызском языке с готовой тематической разметкой.

Файлы: [qad-train_1000.csv](data/raw/qad-train_1000.csv) — 1000 строк и [qad-test_0500.csv](data/raw/qad-test_0500.csv) — 500 строк. Столбцы: `id`, `text`, `labels_set`, `tokenized_text`.

Исходная разметка допускает несколько тем у одной новости. Для учебной задачи оставлены только записи с одной меткой, удалены пустые тексты и нормализованные дубликаты, исключены классы с менее чем 20 документами. Итог: **696 документов, 10 классов**.

Исходные файлы объединены, затем создано собственное стратифицированное разбиение: **556 train и 140 test**. Результаты относятся к этой выборке и не сопоставляются напрямую с исходным benchmark авторов.

## Основные результаты

Числа взяты из сохранённых выводов ноутбуков. При проверке **14 октября 2026 года** модели повторно не обучались.

### ПР-1: настройка окружения и первичный анализ

Ноутбук: [01_used_car_analysis.ipynb](notebooks/01_used_car_analysis.ipynb).

Загружен автомобильный датасет размером **4009 × 12**. Проверены типы столбцов, пропуски, полные дубликаты и категории топлива. Цена преобразована из строки в число; составлен словарь всех 12 исходных признаков. Обоснован выбор данных для проекта о прогнозировании запрашиваемой цены автомобиля. Версии библиотек зафиксированы в `requirements.txt`.

### ПР-2: разведочный анализ данных

Средняя цена — **44 553,19 USD**, медианная — **31 000 USD**. Распределение имеет длинный правый хвост.

- Спирмен, модельный год и цена: **0,6974**.
- Спирмен, пробег и цена: **−0,7552**.
- Манна — Уитни, группы `accident`: **p = 8,31 × 10⁻⁶⁸**, ранговый размер эффекта **−0,3702**.
- Медианы цены: без сообщения об аварии — **35 667,50 USD**, с сообщением — **20 900 USD**.

Все три H0 отклонены при пороге Бонферрони 0,05 / 3 ≈ 0,01667. Отображение `p = 0` для корреляций связано с численной точностью. Найденные связи не доказывают причинность.

### ПР-3: предобработка

ПР-3 и ПР-4 используют шесть исходных признаков: `brand`, `model_year`, `milage`, `fuel_type`, `accident`, `clean_title`. Train/test: **3207/802**, `random_state=42`.

Трансформер переводит пробег в число и добавляет `relative_milage = (milage + 1) / (медиана марки + 1)`. Медианы обучаются только на train; новая марка получает общую медиану train. Выход Pipeline содержит **72 признака**.

В outputs пройдены все три теста: сохранность статистик и входных данных, известные/новые марки и пропуски, полный Pipeline на новых данных.

При увеличении train с 3207 до 160 350 строк медианное время `fit_transform` выросло с **0,0661 до 1,2838 с**, `transform` — с **0,0307 до 0,6816 с**. Самый медленный измеренный шаг применения — собственный трансформер. Повторение строк проверяет скорость, а не качество модели; время зависит от компьютера.

### ПР-4: линейная регрессия на NumPy

| Работа | Модель | Test MAE, USD | Test RMSE, USD | Test R² |
|---|---|---:|---:|---:|
| ПР-4 | Средняя цена train | 35 276,16 | 143 144,98 | −0,002 |
| ПР-4 | NumPy, градиентный спуск | 24 884,72 | 137 787,54 | 0,071 |
| ПР-4 | LinearRegression | 24 705,08 | 137 899,78 | 0,070 |

MAE — средняя абсолютная ошибка цены; RMSE сильнее реагирует на большие промахи. Обе метрики выражены в USD, MSE — в USD². R² безразмерен.

В ПР-4 исследованы скорости **0,001; 0,01; 0,1**, по 5000 обновлений. Минимальный конечный train MSE дала **0,1**. Train MSE собственной модели на **2,03%** выше sklearn. Полное one-hot кодирование со свободным членом допускает неединственные коэффициенты; их различия оцениваются вместе с метриками.

В test встречаются цены выше максимума train; три крупнейшие ошибки дают около **94,4%** суммы квадратов ошибок собственной регрессии. Экстремальная цена сама по себе не доказывает ошибку данных.

### ПР-5: дизельные автомобили

В размеченной выборке **3792 объявления**: 116 дизельных и 3676 остальных, дисбаланс **1:31,69**. Неизвестное топливо исключено. `fuel_type` и `is_diesel` не входят в признаки. Используются год, пробег, марка, коробка передач, сведения об авариях и clean title.

Методы проверяются на одинаковых 15 разбиениях train: 5 folds × 3 повторения. Undersampling применяется только в обучающей части; порог заранее фиксирован на **0,5**. Test: 759 объявлений, из них 23 дизельных.

| Метод | Средний CV F1 | Test precision | Test recall | Test F1 |
|---|---:|---:|---:|---:|
| Без коррекции | 0,0517 | 0,0000 | 0,0000 | 0,0000 |
| class_weight="balanced" | 0,1794 | 0,0942 | 0,7826 | 0,1682 |
| Случайный undersampling | 0,1532 | 0,1010 | 0,8696 | 0,1810 |

По среднему CV F1 выбран вариант с весами классов. На отдельном test undersampling получил более высокий F1; test не используется для повторного выбора метода. Высокая accuracy baseline скрывает отсутствие найденных дизельных автомобилей. Низкая precision ограничивает автоматическое восстановление топлива.

### ПР-6: тематики новостей

TF-IDF обучается только на train: **6968 признаков**, отдельные слова и биграммы.

| Модель | Test accuracy | Test macro-F1 | Test weighted-F1 |
|---|---:|---:|---:|
| DummyClassifier | 0,2500 | 0,0400 | 0,1000 |
| MultinomialNB | 0,5357 | 0,2600 | 0,4619 |
| LogisticRegression | 0,6000 | 0,3619 | 0,5532 |

LogisticRegression лучше в этом сравнении, но для `culture`, `foreign affairs`, `society` и `sports` F1 равен нулю. Одна accuracy скрывает проблемы редких классов. Обработка сохраняет стандартные ө, ү, ң и отрицания, но не нормализует вариант буквы **ӊ**; ограничение описано в выводе ноутбука.

### ПР-7: случайный лес и интерпретация модели

Ноутбук: [07_used_cars_random_forest.ipynb](notebooks/07_used_cars_random_forest.ipynb).

Одиночное дерево и случайный лес обучены для прогнозирования цены на одинаковом разбиении **3207 train / 802 test**. Предобработка упрощена относительно ПР-4: без масштабирования и `relative_milage`.

| Модель | Test MAE, USD | Test RMSE, USD | Test R² |
|---|---:|---:|---:|
| Медианный baseline | 32 865,97 | 144 218,92 | −0,018 |
| Одиночное дерево | 25 270,65 | 135 584,79 | 0,101 |
| Случайный лес | 21 808,88 | 135 476,47 | 0,102 |

По трёхкратной кросс-валидации выбраны **300 деревьев, max_depth=None, min_samples_leaf=1**. Средняя CV MAE — **14 222,80 USD**. Лес уменьшил test MAE относительно дерева примерно на **13,7%**, но R² остаётся около 0,10, поэтому качество прогноза ограничено.

MDI и permutation importance выделили марку, пробег и модельный год; порядок марки и пробега различается. SHAP рассчитан для трёх test-автомобилей, построены waterfall-графики и даны локальные объяснения. Вклады one-hot столбцов суммированы по исходным признакам; проверено, что они вместе с базовым значением воспроизводят прогноз. Важности и SHAP объясняют поведение модели, а не причинное влияние характеристик на цену.

## Установка и запуск

1. Открыть в VS Code папку `ml-social-media-sleep`.
2. Установить расширения Python и Jupyter, если их ещё нет.
3. В PowerShell из папки проекта выполнить:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если `.venv` уже существует, создание можно пропустить. Активация не обязательна: команды явно используют Python окружения.

4. Открыть нужный `.ipynb` из `notebooks/`.
5. В **Select Kernel** выбрать Python из `.venv\Scripts\python.exe`.
6. Проверить CSV в `data/raw/`. Для ПР-1 и ПР-2 рабочая папка kernel должна быть `notebooks/`: загрузка использует `../data/raw/used_cars.csv`. Проверить рабочую папку можно через `Path.cwd()` после `from pathlib import Path`.
7. Выполнить **Restart Kernel → Run All** и сохранить ноутбук с outputs.

Рекомендуемый порядок чтения — № 1–7. Подбор параметров леса в ПР-7 может занять заметное время.

Зависимости зафиксированы в [requirements.txt](requirements.txt): NumPy, pandas, matplotlib, seaborn, SciPy, scikit-learn, ipykernel, SHAP. В ПР-2/3/7 остаются `%pip install` без указания версий; окружение следует устанавливать по `requirements.txt`.
