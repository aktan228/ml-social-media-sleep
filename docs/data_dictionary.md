# Словарь признаков

| Столбец | Смысл и единицы | Смысловой тип |
|---|---|---|
| brand | Марка автомобиля | Категориальный |
| model | Модель и комплектация | Категориальный |
| model_year | Модельный год; не обязательно точная дата производства | Числовой, дискретный |
| milage | Пробег в милях; написание имени сохранено из источника | Числовой по смыслу, строка в CSV |
| fuel_type | Вид топлива; есть пропуски и служебные значения | Категориальный |
| engine | Текстовое описание двигателя, иногда мощность и объём | Текстовый |
| transmission | Описание коробки передач | Категориальный, требует унификации |
| ext_col | Цвет кузова | Категориальный |
| int_col | Цвет салона | Категориальный |
| accident | Сведения об авариях или повреждениях в объявлении | Категориальный |
| clean_title | Указание clean title в объявлении; пропуск не равен No | Категориальный |
| price | Запрашиваемая цена в долларах США; будущая цель регрессии | Числовой по смыслу, строка в CSV |
